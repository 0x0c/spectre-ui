# site/ — ロードマップ可視化ページ

`docs/roadmap.md` の内容を1ページに可視化した静的サイト。GitHub Pages に公開される。

- 公開先: https://0x0c.github.io/spectre-ui/
- デプロイ: `.github/workflows/pages.yml`（`main` の `site/**` が変わると実行）

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体。各セクションの箱だけを持ち、中身は JS が描画する |
| `assets/roadmap.data.js` | **データはここだけ。** `window.ROADMAP` にマイルストーン・未決事項・リスク・選定サマリを持つ |
| `assets/app.js` | ガントチャート (SVG)、マイルストーンカード、テーブルの描画。依存ライブラリなし |
| `assets/styles.css` | 配色・レイアウト。色はすべて CSS カスタムプロパティ経由で、ライト/ダークを1か所で切り替える |

## 更新のしかた

`docs/roadmap.md` を更新したら `assets/roadmap.data.js` も合わせる。ビルド手順はない。

- マイルストーンのタスクを完了させる → 該当タスクの `done` を `true` にする。進捗メーターとヘッダーの集計に反映される。
- 期間を変える → `weeks: [最短, 最長]`。ガントの軸と「本番投入可能まで」の数字が自動で追従する。

## ローカルで見る

```sh
cd site && python3 -m http.server 8000
# → http://127.0.0.1:8000/
```

## 設計メモ

- **スケジュールは2つの前提を切り替えられる。** 既定は「M1 (iOS/Android) と M2 (エディタ) を並行」。
  `docs/roadmap.md` の担当者前提 (iOS 1名 / Android 1名 / Web・サーバ 1〜2名) に沿う。
  もう一方は全マイルストーンを直列に積んだ上限見積もり。
- **バーの濃い部分が最短ケース、淡い部分が最長ケースまでの振れ幅。** 単一の線で断定しない。
- **色はマイルストーンの順序を表す序数ランプ**（青の単一色相、M0 → M4）。長さの大小を色で二重符号化しない。
- 影響度は色だけでなく**アイコンとラベル**でも示す。ガントには**テーブル表示**を用意してある。
